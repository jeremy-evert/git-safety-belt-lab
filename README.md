# Git Safety Belt Lab

A tiny public practice repository for learning Git and GitHub in the age of AI-assisted coding.

The code in this repository is intentionally simple. The important part is the workflow around the code:

```text
KNOW WHERE YOU ARE
  ↓
KNOW WHAT CHANGED
  ↓
VERIFY WHAT HAPPENED
  ↓
PRESERVE THE GOOD STATE
  ↓
RECOVER WHEN NEEDED
```

## The rule

> **Git is the safety belt.**
>
> AI may help drive the change. The human still owns the commit.

This repository is used by the SWOSU Computing Commons Git + GitHub station.

Do not worry if there is almost nothing here yet. The early commit history is intentional and will become part of the exercise.
